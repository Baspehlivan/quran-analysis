# data-contract

Phase 1 neutral, auditable implementation notes. Raw source bytes are immutable. Derived processes must preserve provenance and avoid claims or hard-coded analytical counts.

## Phase 2B additions

`environment_snapshot`, expanded `analysis_run` provenance fields, `analysis_evidence` evidence hashes, and `export_manifest` sidecars are part of the stable reproducibility contract. Hash specs are documented in `query-hashing.md`, `evidence-hashing.md`, and `ngram-hashing.md`.
